# Changelog

## 5.0.1

- Reaction rules can run supported commands with the reacting person's permissions. Existing rules keep their sender filters. Reactions from other people on messages authored by the linked account require an explicit rule setting.
- The reaction editor explains which commands are available and previews who can trigger a rule and what it will do.
- Levix Plus Auto Reply supports all chats, exclusions, or selected chats, with a separate group switch. It can reply, react, or stay silent. Existing chat selections carry forward.
- Login, Connection, and Overview are more compact. The account card keeps the current display name when WhatsApp replays older messages.
- Gemini chat history recovers from incompatible thought signatures without deleting the conversation.
